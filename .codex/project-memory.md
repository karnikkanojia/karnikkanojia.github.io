# Project Memory

- Do not run browser checks or visual inspections for this portfolio unless explicitly requested. The user will inspect UI changes themselves and provide screenshots or context for edits.
- Keep responsive text sizing close to the hero scale unless the user asks for a deliberately oversized section: hero headline uses `text-xl md:text-2xl lg:text-4xl`, support text uses `text-sm md:text-base`, intro-style section headlines should generally stay around `text-2xl md:text-3xl lg:text-4xl`, and body copy around `text-base md:text-lg`.
